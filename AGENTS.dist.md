## Project notes

- WP Site Starter is the only client named in this repo. Never name another client in code, comments, commit messages, PR titles and descriptions, or docs. Describe a pattern from another project without where it came from.
- Bump the theme's version when pattern files are added or renamed: `Version` in `style.css`, plus `readme.txt` (Stable tag and changelog) and `package.json`. WordPress caches a theme's pattern files until its version changes.
